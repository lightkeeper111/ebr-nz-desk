# EBR NZ Desk static site

Independent New Zealand equity intelligence for global institutional investors.

## Site
- `index.html` — primary landing page and institutional access form
- `research.html` — research approach + selected public work
- `about.html` — founder / operating philosophy
- `styles.css` — site styling
- `script.js` — navigation + access CTA behaviour

## Deployment
Plain HTML/CSS/JS; no build step is required. The access form is configured for Netlify Forms with a honeypot field.
